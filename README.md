Feedstock for [thepeg](https://thepeg.hepforge.org) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

ThePEG: Toolkit for High Energy Physics Event Generation

## Install

```bash
conda install -c hep-forge -c conda-forge thepeg
```
